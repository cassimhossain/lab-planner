Build

      
  1. Drag parts from Components onto the canvas, or open a ready-made circuit from the Library.
    2. 
        
  2. Make a wire: drag from one pin to another, or click a pin and then another. Wires snap to the nearest pin. Click empty space on the way to add bends. Esc cancels.
    3. 
        
  3. Put legs on the breadboard to connect them. Hover a hole to see which holes are joined (green).

      
Code and run

      
  1. Write code on the Code tab, or start from the Code library or Code for this part.
    2. 
        
  2. Press Start simulation. While it runs, press buttons and turn knobs. Click a sensor to change what it senses: for the ultrasonic, PIR, IR and flame sensors, drag the object inside the sensing cone.
    3. 
        
  3. ESP32 web pages, Bluetooth and MQTT open in the Phone tab.

      
Keys

      
  • R rotate · Del delete · Ctrl+Z / Y undo / redo
  • Ctrl+Enter start / stop · Ctrl+S save
  • Mouse wheel or pinch zooms, two-finger scroll or drag empty space moves · + / - zoom · 0 fit · F zoom to the selected part · double-click a part to zoom in, double-click empty space to see everything

Good to know

      
Circuit Lab checks logic and wiring, not exact electrical values. It warns about missing resistors, short circuits and motors on a pin, because those break real parts. The ESP32 runs in teaching mode: pins, ADC, PWM, Serial, servos and displays behave like an ESP32, while Wi-Fi, web pages, MQTT, ESP-NOW and Bluetooth talk to a pretend network in the Phone tab.

      
Built with Wokwi Elements and AVR8js (MIT). Code is compiled by the Wokwi build service, so compiling needs internet.
