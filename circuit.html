Quick start

      
  1. Open Examples and pick one, or add parts from the left.
  2. Draw wires: click a pin, then click another pin. Click empty space to add bends. Esc cancels.
  3. Write your code on the Code tab.
  4. Press Run. While it runs you can press buttons, turn knobs and change sensor values in the part panel.

      
Keyboard

      
  • R rotate the selected part · Delete remove it
  • Ctrl+Enter run / stop · Ctrl+S save · Ctrl+Z undo
  • Mouse wheel zooms, drag empty space to move around.

      
Breadboard

      
Drop a part so its legs sit on breadboard holes and they connect automatically. Holes in one short column (a-e or f-j) are joined; the long + and − rails run along the edges.

      
Libraries you can use

      
Servo, LiquidCrystal, LiquidCrystal_I2C, DHT, Adafruit_NeoPixel, Adafruit_GFX, Wire, EEPROM.

      
Good to know

      
This is a learning simulator: it checks logic and wiring, not exact electrical values. It will warn you about missing resistors, short circuits and motors wired straight to pins, because those break real hardware.
