Build

      
  1. Drag parts from Components onto the canvas, or open a ready-made circuit from the Library.
    2. 
        
  2. Make a wire: drag from one pin to another, or click a pin and then another. Wires snap to the nearest pin. Click empty space on the way to add bends. Esc cancels.
    3. 
        
  3. Put legs on the breadboard to connect them. Hover a hole to see which holes are joined (green).

      
Code and run

      
  1. Write code on the Code tab, or start from the Code library or Code for this part.
    2. 
        
  2. Press Start simulation. While it runs, press buttons and turn knobs. Click a sensor to change what it senses: for the ultrasonic, PIR, IR and flame sensors, drag the object inside the sensing cone.
    3. 
        
  3. ESP32 web pages, Bluetooth and MQTT open in the Phone tab.

      
Bench tools

      
  • Multimeter (the probe button, or M while running): point at any pin or wire to read its voltage and whether it counts as HIGH or LOW.
    • 
        
  • Wire voltages: colours every wire while the simulation runs — red for HIGH, blue for LOW, amber in between, grey for nothing connected.
    • 
        
  • Logic scope: with the multimeter on, click pins to draw how they change over the last two seconds. Six signals at once.
    • 
        
  • Slow motion: the speed buttons next to Start run the whole board as slowly as 1/100 speed, so you can watch a signal move. Space pauses; the step button runs a short slice.
    • 
        
  • Notes: drop a sticky note on the canvas to label a circuit for a worksheet.
    • 
        
  • Save or share: a sharp picture of the circuit, a parts list and wiring table for a lesson plan, the circuit file, or a link that carries the whole circuit.

      
Keys

      
  • R rotate · Del delete · Ctrl+Z / Y undo / redo
  • Ctrl+C / V / D copy, paste, duplicate · Ctrl+A select all · Shift+click adds a part to the selection
  • Space pause while running · M multimeter
  • Ctrl+Enter start / stop · Ctrl+S save
  • Mouse wheel or pinch zooms, two-finger scroll or drag empty space moves · + / - zoom · 0 fit · F zoom to the selected part · double-click a part to zoom in, double-click empty space to see everything

Good to know

      
Circuit Lab checks logic and wiring, not exact electrical values. Transistors, MOSFETs, diodes and the 555 timer are behaviour models rather than analog circuit simulation: the 555 works out its frequency from the resistors and capacitor you wire, but it does not draw a charging curve. It warns about missing resistors, short circuits and motors on a pin, because those break real parts. The ESP32 runs in teaching mode: pins, ADC, PWM, Serial, servos and displays behave like an ESP32, while Wi-Fi, web pages, MQTT, ESP-NOW and Bluetooth talk to a pretend network in the Phone tab.
